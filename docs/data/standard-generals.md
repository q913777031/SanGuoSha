## 1. 约定

### 1.1 文案版本的选择

标准版武将的印刷文案有三代（本文用以下标签）：

| 标签          | 年代                                                 | 特征                                                                                           | 本文来源                                                                         |
| ------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| **2008 初版** | 2008 推广版 / 2009 标准版初印                        | 口语化："你可以立即获得…"、"每回合限用一次"、"回合开始阶段"                                    | QSanguosha 2011-06-30 快照（S2-a）                                               |
| **2012 新版** | 2011/2012 新包装重印                                 | 规范化："每当你受到一次伤害后…"、"每阶段限一次"、"回合开始阶段开始时"、"锁定技/主公技"明确标注 | QSanguosha-v2 2012-07-01 / 2012-12-24 快照（S2-b）                               |
| **2013 修订** | 2013 新版标准版（更换 3 名武将技能并新增袁术、华雄） | "出牌阶段限一次"、"准备阶段开始时"；黄月英、刘备、貂蝉等技能有机制改动                         | QSanguosha-v2 2013-06-05 快照（S2-c）；QSanguosha-v2 master《怀旧-标准》（S2-d） |

**本文"原文"栏采用 2012 新版文案**（它是 2012–2015 年流通最广、且被此后 OL/手杀/FreeKill 现行文案延续语义的版本）。凡 2008 初版或 2013 修订与之**语义不同**的，在"版本差异"中逐条列出；仅措辞不同、语义相同的只注"措辞微调"。2014/2015 年"新标准版"与界限突破的改动一律不采用，仅在必要处注明以免混淆。

### 1.2 技能类型

| 类型       | 含义（引擎视角）                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------------------- |
| 主公技     | 仅主公身份可用；通常同时是触发技（护驾、激将）或锁定技（救援）                                          |
| 锁定技     | 不可选择不发动；多数是静态修正（距离、次数、目标合法性、响应方式），也可是强制触发（救援）              |
| 普通触发技 | 在某个时机点询问"是否发动"，可选                                                                        |
| 主动技     | 出牌阶段由玩家主动发起（含"限一次"和"不限次"两类）                                                      |
| 视为技     | 将某张牌当作另一张牌使用/打出（在"需要使用/打出某牌"的询问时机提供额外选项）；本文归入"修正类·牌的视为" |

| 中文时机                    | 建议事件名                            | 说明                                                             |

| 需要使用或打出【闪】时      | `AskForCardUse/Response(jink)`        | 护驾；视为技 倾国、龙胆 在此处提供选项                           |

### 2.2 取证等级定义

- **已核对**：原文语义在 ≥ 2 个独立来源中一致（S2-b 原文 + S2-c/S2-d/S1/S3 中至少一个语义一致），且基础信息（势力/体力/性别）在 S1 与 S2 一致。
- **单一来源**：某条文案只在一个来源出现、无法交叉。本次无此等级。
- **存疑**：来源之间存在**机制性**冲突（不只是措辞），需要产品决策后才能定稿。

### 3.1 曹操（caocao）

**奸雄 `jianxiong`** —— 普通触发技

- 原文（2012 新版）：每当你受到一次伤害后，你可以获得对你造成伤害的牌。
- 版本差异：2008 初版"你可以立即获得对你造成伤害的牌。"；2013 修订同 2012；FreeKill 现行"当你受到伤害后，你可以获得对你造成伤害的牌。"——语义一致。（2014 新标准版追加"或摸一张牌"二选一，**不采用**。）
- 触发时机：**受到伤害后**（`Damaged`），每次伤害事件触发一次，可选；仅当伤害由牌造成且该牌仍在处理区时有牌可得（【杀】【决斗】【南蛮入侵】【万箭齐发】等；【闪电】判定伤害、技能伤害无牌）。

**护驾 `hujia`** —— 主公技（触发）

- 原文（2012 新版）：主公技，当你需要使用或打出一张【闪】时，你可以令其他魏势力角色打出一张【闪】（视为由你使用或打出）。
- 版本差异：2008 初版"主公技，当你需要使用（或打出）一张【闪】时，你可以发动护驾。所有魏势力角色按行动顺序依次选择是否打出一张【闪】"提供"给你（视为由你使用或打出），直到有一名角色或没有任何角色决定如此做时为止。"；2013 修订"…你可以令其他魏势力角色选择是否打出一张【闪】（视为由你使用或打出）。"——语义一致（依次询问、首个响应者有效）。
- 触发时机：**需要使用或打出【闪】时**（`AskForCardUse(jink)` / `AskForCardResponse(jink)`），仅主公身份；按行动顺序依次询问其他存活魏势力角色，得到一张【闪】即视为你使用/打出并停止询问。

**反馈 `fankui`** —— 普通触发技

- 原文（2012 新版）：每当你受到一次伤害后，你可以获得伤害来源的一张牌。
- 版本差异：2008 初版"你可以立即从对你造成伤害的来源处获得一张牌。"；2013 修订同 2012；FreeKill 现行"当你受到伤害后，你可以获得伤害来源的一张牌。"——语义一致。
- 触发时机：**受到伤害后**（`Damaged`），每次伤害事件一次，可选；需伤害来源存在且有牌（手牌或装备区，手牌为随机/暗选）；无来源伤害（闪电）不触发。

**鬼才 `guicai`** —— 普通触发技

- 原文（2012 新版）：在一名角色的判定牌生效前，你可以打出一张手牌代替之。
- 版本差异：2008 初版"在任意角色的判定牌生效前，你可以打出一张手牌代替之。"；2013 修订"每当一名角色的判定牌生效前，…"；FreeKill 现行"当一名角色的判定牌生效前，你可以打出一张手牌代替之。"——语义一致。（2014 新标准版改为"打出一张牌"可用装备，**不采用**。）
- 触发时机：**判定牌生效前**（`AskForRetrial`），任何角色的判定（含延时锦囊、八卦阵、洛神、刚烈、铁骑等），回合内外均可；原判定牌进入弃牌堆，打出的手牌成为新判定牌。

- 触发时机：**使用【杀】指定目标后**（`TargetSpecified(slash)`）与**使用【决斗】指定目标后 / 成为【决斗】的目标后**（`TargetSpecified(duel)` / `TargetConfirmed(duel)`），锁定；效果为修改对方的响应需求（闪 ×2 / 杀 ×2）。

### 6.3 貂蝉（diaochan）

| 项目     | 值                                                      |
| -------- | ------------------------------------------------------- |
| 势力     | 群                                                      |
| 体力上限 | 3                                                       |
| 性别     | 女                                                      |
| 技能     | 离间 `lijian`、闭月 `biyue`                             |

**离间 `lijian`** —— 主动技（出牌阶段限一次）

- 原文（2012 新版）：出牌阶段，你可以弃置一张牌并选择两名男性角色，视为其中一名男性角色对另一名男性角色使用一张【决斗】。此【决斗】不能被【无懈可击】响应。每阶段限一次。
- 版本差异：2008 初版"出牌阶段，你可以弃一张牌并选择两名男性角色。若如此作，视为其中一名男性角色对另一名男性角色使用一张【决斗】。（此【决斗】不能被【无懈可击】响应）。每回合限用一次"；**2013 修订"出牌阶段限一次，你可以弃置一张牌并选择两名男性角色，令其中一名男性角色视为对另一名男性角色使用一张【决斗】。"（删去"不能被无懈可击"）**；S2-d《怀旧-标准》"…此【决斗】不能被【无懈可击】响应。"；FreeKill 现行"出牌阶段限一次，你可以弃置一张牌并选择两名其他男性角色，后选择的角色视为对先选择的角色使用了一张不能被【无懈可击】的【决斗】。"——2008/2012/S2-d/S1 四方一致保留"不能被无懈可击"，仅 2013 快照不同。
- 触发时机：**出牌阶段主动技，限一次**（`Active(Play, once)`）；代价：弃置一张牌（手牌或装备）；两名目标均为男性（貂蝉为女性，自然不含自己）；视为的【决斗】不计入貂蝉的出牌记录，伤害来源按【决斗】规则判定；空城者不能成为该【决斗】目标；无双对该【决斗】生效。
- 建议：采用 2012（不能被【无懈可击】响应）。

**闭月 `biyue`** —— 普通触发技

- 原文（2012 新版）：回合结束阶段开始时，你可以摸一张牌。
- 版本差异：2008 初版"回合结束阶段，可摸一张牌"；2013 修订"结束阶段开始时，你可以摸一张牌。"；FreeKill 现行同 2013——语义一致。
- 触发时机：**结束阶段开始时**（`PhaseStart(Finish)`），可选。
